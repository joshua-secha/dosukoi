# どすこい計算ゲーム

小学生向けの計算練習ゲームです。相撲をテーマにした楽しい四則演算の学習ツールです。

![ゲーム画面](assets/screenshot.png)

## 機能

- **四則演算練習**: 足し算、引き算、掛け算、割り算
- **適応型難易度**: プレイヤーの回答速度に応じて難易度が自動調整
- **プッシュ/プル機能**: 間違えた問題は再出題される
- **隠しボス**: 5勝で強敵が出現！
- **番付システム**: スコアに応じて序ノ口から横綱まで昇進
- **BGMと効果音**: ゲームを盛り上げる音楽と効果音

## 遊び方

1. 「はっけよい！」ボタンでゲーム開始
2. 表示される計算問題に答える
3. 正解すると相手を押し出す
4. 不正解だと押し返される
5. 相手を土俵外に押し出せば勝利！

## 技術スタック

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API

## ローカルで実行

```bash
# リポジトリをクローン
git clone https://github.com/あなたのユーザー名/dosukoi-game.git

# ディレクトリに移動
cd dosukoi-game

# ローカルサーバーを起動（Pythonの場合）
python -m http.server 8000

# ブラウザで開く
# http://localhost:8000
```
